## 📌 Project Overview
This repository contains a collection of custom **Client Scripts** and **UI Policies** implemented on the ServiceNow `incident` table. Designed as a portfolio item for the **Skill Wallet Project**, it demonstrates client-side form validations, dynamic field behaviors, and automated state-handling workflows.
